# Student Management REST API

## Setup

```bash
npm install
npm start
```

The server runs on:

http://localhost:3000

## APIs

GET /students

GET /students/:id

POST /students

PUT /students/:id

DELETE /students/:id

## POST Body

```json
{
  "name": "Neha",
  "course": "BCA"
}
```

## PUT Body

```json
{
  "name": "Neha Sharma",
  "course": "BTech"
}
```
